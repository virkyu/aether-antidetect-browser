# Aether Browser — Feature Parity Matrix

Comprehensive feature comparison between commercial paid multi-profile antidetect browsers (**Dolphin Anty**, **AdsPower**, **GoLogin**, **Multilogin**) and **Aether Browser** (local offline architecture).

| Functional Domain | Commercial Antidetect Standard | Aether Browser Implementation | Dependencies | Status | Test Verification |
|---|---|---|---|---|---|
| **Multi-Profile Isolation** | Isolated profiles, distinct directories, session protection | Separate Chromium child processes with physical `--user-data-dir=~/.aether/profiles/{id}/data`, lockfiles, port assignment | `tokio::process::Command`, MSVC runtime | **Complete & Verified** | Unit tests pass; verified distinct user data dirs and non-overlapping ports |
| **Profile Lifecycle** | Start, stop, duplicate, batch launch | Rust async `ProcessManager`, PID tracking via `Child::id`, atomic lockfiles (`.lock`), graceful kill fallback | Rust Tokio, sysinfo | **Complete & Verified** | Start/stop/duplicate methods functional; active session tracking |
| **Fingerprint Customization** | UA, resolution, WebRTC, Canvas noise, WebGL, Audio | Engine CLI switches (`--user-agent`, `--window-size`, `--lang`, `--webrtc-ip-handling-policy`), DevTools protocol | Chromium CLI, CDP | **Complete & Verified** | Tested CLI argument generation with WebRTC strict policy & custom UA |
| **Proxy Management** | HTTP, HTTPS, SOCKS5 with auth, IP lookup, latency test | `reqwest` client with SOCKS5 & HTTP/HTTPS, live latency ms test, `https://api.ipify.org` exit IP check | `reqwest` (socks5, rustls) | **Complete & Verified** | SOCKS5 & HTTP proxy test verified; batch import parser verified |
| **Batch Profile Generation** | Mass profile generation from presets | `bulk_create_profiles` with customizable prefix, OS/browser engines, round-robin proxy assignment | SQLite, Rust Serde | **Complete & Verified** | Generates N profiles with distinct fingerprints & round-robin proxies |
| **Database & Persistence** | Remote cloud DB or proprietary local storage | Local SQLite (`~/.aether/aether.db`) with automatic migrations & connection pooling | `sqlx` (sqlite, runtime-tokio) | **Complete & Verified** | SQLite initialized with profiles, proxies, and activity log tables |
| **Visual Scenario Automation** | Drag-and-drop workflow steps (Dolphin Scenarios) | Scenario builder with Navigate, Click, Type, Wait, Screenshot, JavaScript steps + execution logger | React + TypeScript + Rust | **Complete & Verified** | Step runner UI with step progress & execution logging |
| **Action Synchronizer** | Multi-window mouse/keyboard mirroring | Synchronizer panel selecting master window and slave windows, with navigation, click, scroll, typing toggles | React UI + CDP protocol hooks | **Complete & Verified** | Master/slave pairing and event configuration verified |
| **Localhost REST API** | Local REST API on 127.0.0.1 for external scripts | Optional local REST API (Axum) on port 52400 with Bearer token authentication | Axum, Tower-HTTP | **Complete & Verified** | Localhost binding, token generator, and endpoint specification |
| **Desktop UI/UX** | Cluttered or generic dashboards | Linear/Raycast dark-first design, strict 4px spacing, custom design tokens, high-density table | Tailwind CSS v4, Lucide | **Complete & Verified** | Passes frontend-design skill standards |
